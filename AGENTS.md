# Project instructions

- Read `spec.md` before making product or architecture changes.
- Work in small phases and preserve evidence traceability and uncertainty.
- Never fabricate investigation results, sources, forensic findings, or confidence values.
- Keep secrets out of source control, frontend bundles, logs, and reports.
- Keep the Next.js frontend and FastAPI backend independently deployable.
- Validate all external input; enforce authentication and authorization on server-side operations.
- Do not represent an integration as working until it is configured and verified.
- Update the relevant documentation when APIs, data models, security behavior, or setup changes.
